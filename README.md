# Real Estate Prospecting App

Flat-file Cloudflare Worker demo for ranking synthetic Arizona real estate contacts by propensity to sell.

## Files

- `index.html`, `app.js`, `style.css`: dashboard UI
- `worker.js`: serves static assets and `/api/leads` JSON routes
- `scoring.js`: deterministic scoring and fallback explanation helpers
- `data.json`: precomputed synthetic leads exported from the workbook
- `wrangler.toml`: Cloudflare Worker and Assets binding config

## Local Development

```bash
npm install
npm run dev
```

Then open http://127.0.0.1:8787 and check:

- `/` renders the ranked dashboard
- `/api/leads` returns all leads sorted by score
- `/api/leads/C00021` returns one lead

## Deploy

```bash
npx wrangler login
npm run deploy
```

The first deploy returns a public `*.workers.dev` URL.

## Governance

This MVP uses synthetic data, no auth, and no database. Do not load real client PII until the app has authentication, an audit log, and a real ingestion path.

Scores and ranking come from precomputed structured fields. Explanation text is generated by `scoring.js` (`ENABLE_LLM_EXPLANATIONS` is off). If the LLM path is enabled later, it may only rephrase existing facts — it must not invent numbers or change the score.
